# AgenciaViajes
Aplicación web para búsqueda y reserva de vuelos y paquetes turísticos.
## Nueva funcionalidad

Se está desarrollando la funcionalidad de búsqueda de vuelos para permitir a los clientes consultar vuelos disponibles según el origen, destino y fechas seleccionadas.

### Características

- Búsqueda por ciudad de origen.
- Búsqueda por ciudad de destino.
- Selección de fecha de salida.
- Selección de fecha de regreso.
- Preparación para integrar servicios externos de reservas.
